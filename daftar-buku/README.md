## Daftar Buku — Laravel, Blade, dan Tailwind CSS

Aplikasi Perpustakaan Mini berbasis Laravel yang mengimplementasikan operasi CRUD data buku.

### Fitur

- Menampilkan daftar buku
- Menambahkan buku
- Melihat detail buku
- Mengubah data buku
- Menghapus data buku
- Pencarian berdasarkan judul dan penulis
- Pagination lima buku per halaman
- Validasi form
- CSRF protection
- Seeder data contoh
- Blade Template
- Tailwind CSS

### Struktur Data Buku

- Judul
- Penulis
- Tahun Terbit
- Sinopsis

### Teknologi

- PHP
- Laravel 12
- SQLite
- Blade
- Tailwind CSS
- Vite
